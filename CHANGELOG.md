# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0+4 - 2026-07-06

- Added more world currency to choose from, and ability to use custom currency.
- Improved and stabilized the debt tracking workflows.
- Refined backup, restore, export, and attachment-related behavior.
- General quality, UI, and reliability improvements.

## 1.0.0+3 - 2026-06-28

- Initial public release of Debt Book.
- Added offline debt tracking for lent and borrowed records.
- Added partial payments, transaction history, and settlement handling.
- Added export, backup/restore, and optional contact/image integrations.
